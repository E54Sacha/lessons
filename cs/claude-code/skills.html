📘Claude Code skills

Instructions you write once, and Claude reads only when it needs them.

beginnercs2026-11-26example: claude-dev-toolkit

💡The idea

A skill is a set of instructions you write once and Claude reuses whenever it's needed. Instead of explaining the same process every time ("ask me questions first, then write a plan"), you save it in a file.

💡 Think of it like this

A skill is a recipe card. Claude doesn't memorize every recipe: it glances at the card titles, and only reads a full card when it's time to cook that dish.

📖Key words

Skill
A folder with a SKILL.md file that teaches Claude how to do one kind of task.
Frontmatter
The few lines between --- at the top of the file, holding the name and description.
Description
One or two sentences saying what the skill does and when to use it.
Plugin
A package that can hold several skills (and other tools) so they install together.
Slash command
Typing /plugin-name:skill-name to start a skill yourself.

⚙️How it works

  1. When Claude Code starts, it reads only the name and description of every skill.
  2. You send a message.
  3. If your message matches a skill's description, Claude opens that skill and reads its full instructions.
  4. Claude follows the instructions step by step, reading extra files only when a step needs them.
  5. You can also skip the matching and start a skill directly with its slash command.

🔍Example

The scope-project skill turns a vague project idea into a requirements file. Its description lists the phrases that should start it ("I want to build", "plan this") and when not to use it (bug fixes). It reads its template only when it reaches the writing phase.

---
name: scope-project          # used in /claude-dev-toolkit:scope-project
description: Turns a project idea into a REQUIREMENTS.md ...
  Use when the user ... says "new project idea", "I want to build", "plan this" ...
  Do not use for changes to code in an existing project, bug fixes ...
---                          # above: always loaded · below: only when the skill starts
✅ Tip

Write the description with the words you would actually type. Saying when not to use the skill is just as useful.

⚖️Why use it

✅ Advantages

  • You stop repeating the same instructions in every conversation.
  • Claude follows the same steps every time, so results are consistent.
  • Only descriptions load at the start, so many skills cost very little.

⚠️ Limits

  • If the description is vague, Claude won't know when to use the skill.
  • Instructions are guidance, not hard rules: Claude can still skip a step.

🔀Other ways

CLAUDE.md file: for rules that apply to every conversation in a project, not to one kind of task.
Subagent: when the task should run in its own separate context, like a long code explanation.

🎯Quiz

  1. What is a skill in Claude Code?

    Answer

    A folder with a SKILL.md file: a short description, then instructions Claude follows for one kind of task. You write it once and reuse it.

  2. The few lines between the two --- at the top of a skill file are called the _____.

    Answer

    Frontmatter. It holds the skill's name and description.

  3. How does Claude decide when to use a skill?

    1. It runs every skill on every message
    2. It reads all descriptions and opens the skill whose description matches your message
    3. It only uses skills you start with a slash command
    4. It picks one at random
    Answer

    B. Claude always reads every description, and opens a skill when your message matches it. C is tempting, but slash commands are only one of the two ways to start a skill.

  4. Is it true that Claude reads the full instructions of every skill when it starts?

    Answer

    No, false. At the start it only reads each skill's name and description. The full instructions load only when the skill is used.

  5. Is it true that you can start a skill yourself with a slash command?

    Answer

    Yes, true. Typing /plugin-name:skill-name starts it directly, without waiting for Claude to match it.

  6. Why does a skill read extra files, like a template, only when a step needs them?

    Answer

    To keep Claude's context small: you only pay for a file when it's actually needed.

  7. What happens if a skill's description is too vague?

    1. The skill fails to install
    2. Claude asks you to rewrite it
    3. Nothing, descriptions are optional
    4. Claude often doesn't know when to use it
    Answer

    D. Claude matches your message against the description, so a vague one rarely matches. A is tempting, but the skill still installs fine.

  8. A _____ is a package that can hold several skills, so they install together.

    Answer

    Plugin. It bundles skills (and other tools) into one installable package.
