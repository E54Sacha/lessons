⚛️Atoms and elements

Everything is made of atoms, and the number of protons inside an atom decides which element it is.

beginnerchemistry2026-11-26

💡The idea

An atom is the tiny building block of all matter. It has a small heavy centre, the nucleus, made of protons and neutrons. Light electrons move around it. The number of protons is the atom's ID card: every atom with 6 protons is carbon, every atom with 8 is oxygen. An element is simply one kind of atom, and the periodic table lists all of them in order.

💡 Think of it like this

Atoms are like LEGO bricks that differ only by how many studs they have. Count the studs (the protons) and you know exactly which brick (which element) you hold.

📖Key words

Nucleus
The tiny, heavy centre of an atom, holding the protons and neutrons.
Atomic number (Z)
The number of protons in an atom; it decides the element.
Mass number (A)
The number of protons plus neutrons in the nucleus.
Element
A substance made of only one kind of atom, all with the same atomic number.
Group / period
A column / a row of the periodic table.

⚙️How it works

  1. Protons name the element: the atomic number Z is the number of protons.
  2. Electrons balance protons: a neutral atom (no overall charge) has as many electrons as protons, so the + and − cancel.
  3. Neutrons fill in the mass: neutrons = mass number − atomic number, or \( N = A - Z \).
  4. The periodic table orders elements by Z: H is 1, He is 2, Li is 3, and so on, reading left to right, row by row.
  5. Columns group look-alikes: elements in the same group have the same number of outer electrons, so they react in similar ways.
⚠️ Common mistake

The mass number is not the number of neutrons. It counts protons and neutrons together, so subtract Z to get the neutrons.

🔍Example

The periodic table tile for carbon shows atomic number \( Z = 6 \). The most common carbon atom, carbon-12, has mass number \( A = 12 \). How many of each particle does it have?

Step 1: protons

$$\text{protons} = Z = 6$$

Step 2: electrons (neutral atom)

$$\text{electrons} = \text{protons} = 6$$

Step 3: neutrons

$$N = A - Z = 12 - 6 = 6$$

6

6

Check: carbon-14, used to date old bones, has \( A = 14 \). It is still carbon (6 protons), but it has \( 14 - 6 = 8 \) neutrons.

⚖️Why use it

✅ Advantages

  • Two numbers (Z and A) tell you the full particle count of any atom.
  • The periodic table's layout lets you predict how an element behaves from its column.

⚠️ Limits

  • The "electrons on rings" picture is a simplification; real electrons are spread out in clouds.

🔀Other ways

Electron cloud model: shows electrons as fuzzy regions where they are likely to be, closer to reality.
Isotope notation: writes the atom as \( ^{12}_{6}\text{C} \), with A on top and Z below, a compact way to give both numbers.

🎯Quiz

  1. The tiny centre of an atom, where protons and neutrons sit, is called the _____.

    Answer

    Nucleus. Protons and neutrons are packed in the nucleus; electrons move around it.

  2. Which particle of an atom has a negative charge?

    1. Proton
    2. Neutron
    3. Nucleus
    4. Electron
    Answer

    D. Electrons carry a −1 charge. Protons are +1, neutrons have no charge, and the nucleus is not a single particle.

  3. Is it true that neutrons have a positive charge?

    Answer

    No, false. Neutrons have no charge at all, which is where their name comes from ("neutral"). Protons are the positive ones.

  4. The number of protons in an atom is called its _____.

    Answer

    Atomic number. The atomic number (Z) counts the protons, for example 6 for carbon.

  5. Is it true that two atoms with different numbers of protons can be the same element?

    Answer

    No, false. The number of protons defines the element. 6 protons is always carbon; 7 protons is always nitrogen.

  6. Why does a neutral atom have the same number of electrons as protons?

    Answer

    Each proton is +1 and each electron is −1. With equal numbers, the charges cancel, so the atom has no overall charge.

  7. What does the mass number of an atom count?

    1. Only the protons
    2. The protons plus the neutrons
    3. The protons plus the electrons
    4. Only the neutrons
    Answer

    B. The mass number counts everything in the nucleus. D is a common mistake: to get only the neutrons, you must subtract the atomic number.

  8. An atom has atomic number 11 and mass number 23. How many neutrons does it have?

    1. 11
    2. 23
    3. 12
    4. 34
    Answer

    C. Neutrons = mass number − atomic number = 23 − 11 = 12. B is tempting, but 23 counts protons and neutrons together.

  9. A neutral atom has 3 protons and 4 neutrons. How many electrons does it have, and why?

    Answer

    3 electrons. In a neutral atom the electrons balance the protons; neutrons have no charge, so they do not change the count. (This atom is lithium.)

  10. Is it true that the periodic table orders the elements by increasing atomic number?

    Answer

    Yes, true. Reading left to right and row by row, each element has one more proton than the one before: H is 1, He is 2, Li is 3…

  11. Elements in the same column of the periodic table, called a _____, behave in similar ways.

    Answer

    Group. A column is a group; a row is a period.

  12. Why do elements in the same group react in similar ways?

    Answer

    Because they have the same number of outer electrons, and the outer electrons are what take part in reactions. Lithium and sodium both have 1, so both are very reactive.

  13. Is it true that almost all of an atom's mass is in its nucleus?

    Answer

    Yes, true. Protons and neutrons are each about 2000 times heavier than an electron, so the electrons add almost nothing to the mass.
